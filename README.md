# Examen Practico Api EduSmart - David Leandro Correa Beltrán

## Requerimiento
La startup EduSmart está diseñando el backend de su plataforma de cursos en línea. Se le ha asignado la tarea de construir la primera fase del prototipo, la cual consiste en:

1) Definir la estructura de la base de datos para los cursos mediante entidades JPA y

2) Crear un servicio web (Endpoint GET) que genere anuncios publicitarios automáticos para los cursos utilizando Inteligencia Artificial.

## Endpoint de prueba

Copiar y pegar en el navegador

```
http://localhost:8090/examen/api/edusmart/publicidad?tema=Java&audiencia=programadores
```
